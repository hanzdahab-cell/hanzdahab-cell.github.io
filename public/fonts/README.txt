The project uses the following SIL Open Font License fonts:

1. Primary Display Font: Bebas Neue (Dharma Type, 2010 SIL OFL)
   - Used for: Headlines, major titles, heroic numbers, badges, display banners
   - Local file: /fonts/BebasNeue-Regular.ttf
   - Google Fonts: family=Bebas+Neue

2. Secondary Body & UI Font: Alata (Sorkin Type / Spyros Zevelakis, 2016 SIL OFL)
   - Used for: Body copy, navigation links, cards, buttons, UI labels, descriptions
   - Local file: /fonts/Alata-Regular.ttf
   - Google Fonts: family=Alata

3. Editorial Hook Accent: Tidal Astral Grotesk Regular
   - Local file: /fonts/tidal-astral-grotesk-regular.ttf

4. Arabic Typography System:
   - Display / Headlines: Beiruti (Google Fonts / SIL OFL)
   - Body / Content: Alan Sans (Google Fonts / SIL OFL)
